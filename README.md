# 柏宝箱 iOS 精简版 (0.30.1-ios)

基于柏宝箱 0.30.0 的非官方精简分支,专为 **iOS 浏览器访问云端酒馆** 的场景定制。
原作者声明:自用可随意修改,禁止商用。本分支同样遵守,仅限自用,禁止商用。

## 为什么要精简

原版的"长聊天渲染优化"依赖 `content-visibility`,该特性在 iOS 的 WebKit 内核上
存在渲染空白与进程崩溃问题(表现为频繁白屏)。此外多项功能依赖柏宝库服务端插件,
未安装后端时只会产生无效请求。本分支移除全部 iOS 不兼容与后端依赖功能。

## 已移除

- 长聊天渲染优化(content-visibility,iOS 白屏元凶)
- 生成完成提示音 + 静音保活
- 消息生成完成滚动定位
- 聊天保存 Gzip 压缩
- 切换美化优化(Shadow Property)
- 正则 Vue 分组管理器
- 性能追踪面板
- 全部柏宝库后端功能:Settings/角色列表/最近聊天加速、Manifest 合并、
  消息后台生成、Tokenizer 批量计数、美化主题懒加载、预设自动备份/备份预览、
  预设全局提示词库、管理聊天文件的柏宝库快速搜索(已改走酒馆原生轻量接口)
- 聊天文件列表与头像懒加载中的 content-visibility(保留 contain)

## 保留

- 预设全家桶:分组、收藏、拖拽优化、快速操作、界面折叠、切换快速刷新
- 减少加载楼层数(iOS 上最重要的流畅来源,建议保持开启)
- 移动端键盘三件套:输入框响应优化、禁止输入法自动弹出、编辑时禁用自动滚动
- 管理聊天文件加速(原生接口)、滚动优化、关闭清理
- 主页最近聊天直达、拼音搜索优化、头像懒加载
- CodeMirror 编辑器组:预设内容、自定义 CSS、角色描述
- 世界书优化与新布局、楼层目录、双击/三击编辑、删楼后快速编辑

## 安装

把整个文件夹放入酒馆 `public/scripts/extensions/third-party/` 下即可。
仅需 `dist/` 与 `manifest.json` 即可运行;`src/` 为源码,供后续自行修改重新构建
(`npm install && npm run build`)。
